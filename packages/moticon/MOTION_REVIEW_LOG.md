# Moticon Manual Motion Review

This is the human-review ledger for the 343-icon enhanced set. An icon is marked **signature** only after its SVG has been read, its mechanic has been redesigned around its own parts, and the rendered result has been replayed in isolation. Generated source auditing alone does not qualify.

### Visibility pass

`Home`, `Lamp`, and `Keyboard` received an additional small-size readability pass. Their semantic action was retained, while travel distance, active contrast, and reaction amplitude were increased so the mechanic remains obvious at 24 px rather than only at the 64 px review size. The entire first manual batch was also corrected to expose the same choreography through hover, tap, and forced playground replay.

## Existing reference signatures

`Heart`, `Bell`, `Rocket`, `Sparkles`, and `Download` remain the original hand-authored reference compositions. They stay in the signature set and will be rechecked alongside the appropriate later review batches.

## Remaining review rule

The remaining icons are not considered manually complete merely because they build or render. Each must receive the same source read, semantic-part decision, isolated action-frame inspection, multi-size replay, reduced-motion check, and console check before it is promoted to signature status.
